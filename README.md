# ตารางเวร สิบเวร — ร้อย.ทม.ที่ 2 ทม.รอ.พัน 2

เว็บดูตารางเวรสิบเวรรายคนรายเดือน ทุกคนดูได้ไม่ต้องล็อกอิน แก้ไขได้เฉพาะแอดมิน (ตรวจรหัสที่ Google Apps Script)

- `index.html` หน้าเว็บ
- `js/config.js` ใส่ Web app URL ของ Apps Script (เว้นว่าง = โหมดทดลอง)
- `js/engine.js` ตัวคำนวณตารางเวร
- `js/app.js` ส่วนแสดงผลและหน้าแอดมิน
- `js/seed.js` รายชื่อตั้งต้น (ใช้ในโหมดทดลอง)

หลังบ้าน (Google Apps Script) อยู่ในไฟล์ `DR_Code.txt` แยกต่างหาก ไม่ได้เก็บไว้ใน repo นี้
